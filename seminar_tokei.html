統計の基礎

データを分析するうえで前提となる、統計の基礎知識をまとめています。

データと変数

01データと変数

データを分析にかけるには、まず「整然データ（tidy data）」と呼ばれる形に整えておく必要があります。整然データとは、次の2つの条件を満たすデータの形式のことです。
  • 各変数が1つの列をなす
  • 各観測が1つの行をなす

具体例：mpgデータ

具体的に見てみましょう。以下は、自動車の燃費データ mpg の先頭6台分を抜き出したものです。

manufacturermodeldisplcyldrvctyhwyclass
audia41.84f1829compact
audia41.84f2129compact
audia42.04f2031compact
audia42.04f2130compact
audia42.86f1626compact
audia42.86f1826compact

mpg（head(mpg)の一部）。displ=排気量、cyl=気筒数、drv=駆動方式、cty=市街地燃費、hwy=高速道路燃費、class=車種区分。

この表では、1行が1台の車（1つの観測）に対応しています。たとえば1行目は、排気量（displ）1.8、気筒数（cyl）4、駆動方式（drv）f、市街地燃費（cty）18、高速道路燃費（hwy）29、車種区分（class）compact という値を持つ、audi a4という1台についての観測です。

一方、1列が1つの変数に対応しています。displ列を縦に見ると、6台それぞれの排気量が並んでおり、これは「排気量」という1つの変数の値の集まりです。同様にhwy列は6台の高速道路燃費、class列は6台の車種区分という、それぞれ1つの変数を表しています。

変数の種類

変数は、値の性質によって量的変数と質的変数に分けられます。mpgの列で分類すると、次のようになります。

量的変数
  • 連続変数：displ（排気量）、hwy・cty（燃費）— 数値の大小・差に意味があり、小数などの細かい値も取りうる
  • 離散変数：cyl（気筒数）— 4・6・8のように、整数の値しか取らない
質的変数
  • 名義変数：class（車種区分）、drv（駆動方式）、manufacturer（メーカー）— カテゴリを表すだけで、値の間に順序はない
  • 順序変数：mpgには該当する列がないが、たとえば「満足度（低・中・高）」のように、順序には意味があっても差の大きさには意味がない変数
よくある誤り：
質的変数を数値に置き換えて、平均を計算してしまうことがあります。たとえば class 列を compact = 1, midsize = 2, suv = 3 のように数値化し、その平均を取っても、「車種の平均」に相当する値は存在しません。

1・2・3という数字は単なる区別のためのラベルであり、順序も大小も意味を持たないため、平均という演算自体が無意味になります。

量的変数か質的変数かによって、その後の記述統計・可視化・回帰分析で使える手法が変わるため、分析の前に必ず区別しておく必要があります。

Rで確認する

実際にデータを扱う際は、まず観測数・変数数・先頭のデータを確認します。

  • head(df) — 先頭数行と各列の型を確認
  • nrow(df) — 行数（観測数）
  • ncol(df) — 列数（変数の数）
補足
head(df) の出力では、列名の下に<chr>・<dbl>・<int>といった型が表示されます。<chr>（文字列）の列はおおむね質的変数、<dbl>・<int>（数値）の列はおおむね量的変数に対応しますが、cylのように数値型でも実質的にはカテゴリとして扱いたい変数もあるため、型だけで機械的に判断せず、その変数が何を表しているかを確認することが大切です。
